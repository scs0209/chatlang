## Problem Statement

AI coding-agent sessions (Claude Code, Codex, Cursor) are dense JSONL/logs. Existing tools turn them into **chat/trace viewers** (debug, replay) or treat natural language as something that **compiles into** a real language. Missing: a shareable **programming-language surface** where the conversation *is* the source — optimized for HN/Twitter “whoa” and GitHub followers, not for production debugging.

## What Makes This Cool

Paste a session → it renders as syntax-highlighted **source code** (`turn`, `think`, `tool`, `say`, …). One screenshot reads as “a new language,” not “another chat UI.” Slogan (draft): **Your agent session, as source code.**

### Monorepo sketch

```

packages/ir/
packages/parse-claude/
packages/parse-codex/
packages/parse-cursor/
packages/print/           # emit(ir) -> { text, tokens[] }
packages/fixtures/        # golden inputs + expected .chatlang (no LFS required)
```

### `print` emit contract

```ts
export type TokenType = "keyword" | "ident" | "string" | "comment" | "punct";
export interface Token { start: number; end: number; type: TokenType } // UTF-16 offsets into `text`
export function emit(ir: IrSession): { text: string; tokens: Token[] };
```

String literals in emitted text: **JSON-style escaping** (`\"`, `\\`, `\n`, `\t`; other controls as `\uXXXX`). Same rules for golden `.chatlang` files.

### IR (v0.1 TypeScript sketch)

```ts
export type IrEvent =
  | { type: "user_message"; text: string }
  | { type: "assistant_message"; text: string }
  | { type: "thinking"; text: string }
  | { type: "tool_call"; name: string; argsJson: string } // single JSON string
  | { type: "tool_result"; toolName?: string; ok: boolean; summary: string }
  | { type: "meta"; key: string; value: string };

export interface IrSession {
  sourceFormat: "claude" | "codex" | "cursor";
  events: IrEvent[];
  truncated?: boolean; // set when soft size cap applied
}
```

`raw` bags are **not** required in v0.1 (roadmap only).

### Print surface (v0.1 grammar — newline-terminated statements, **no** semicolons)

```
turn user() {
  say "..."
}

turn agent() {
  think "..."
  tool Read("{\"path\":\"src/auth.test.ts\"}")
  result ok "..."
  say "..."
}
```

Rules:
- Statement terminator: **newline only**.
- `tool Ident(stringLiteral)` only; complex args → one JSON string literal.
- `tool_result` → `result ok|err "..."` (summary, redact-applied). **Omission is print-only:** emit first **20** `tool_result` events, then one `// omitted: tool_result×N` for the remainder. Parsers always include tool_result events in IR when present (no parser-side omit). Drop `omittedToolResults` from IR; use `truncated` only for size caps.
- `meta` → `// meta key=value` comments (or omit if empty).

### Auto-detect (v0.1)

Scan first **50** lines (or 64KB). Each line may contribute **at most one** format hit (first matching signature wins for that line). If one format has hits ≥ **3** and strictly more than others, auto-select it. **Tie** (two formats both ≥3, or equal top scores) → keep current tab + low-confidence. Else keep tab / ask. Signatures defined next to each fixture’s field table after capture.
